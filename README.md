# Luna Cafe Website

A modern and responsive cafe website built with React, Vite, and Tailwind CSS.

## Features

- Cafe menu with prices
- Photo gallery
- About section
- Opening hours
- Contact and reservation form
- Mobile-friendly design

## Technologies Used

- React
- Vite
- Tailwind CSS
